# Security preservation of public refresh

This is a conditional reduction for the implemented public evaluator. It is
not a proof that the joint setup assumption below follows from ordinary RLWE,
nor a claim that the native parameters provide 128-bit security.

## Exact premise

Let Setup publish the work public key and the complete evaluation material
generated by `PublicRefreshCircuitPlan::generate_with_rng`. Its pinned graph
contains 659 RLWE ciphertexts in the native tuple, with W→S→B→W dependencies
and W²→W, B²→B, and sigma(B)→B self relations. The two phase banks expose
encoded shifted source-secret functions in different plaintext trays. The
return receiver is an embedded work secret, with effective dimension 8192.

Define the **joint-setup work IND-CPA experiment** as follows:

1. Run actual key-holder setup with a cryptographically secure RNG; give the
   adversary all public evaluator material and public metadata.
2. The adversary selects two admissible plaintext polynomials of the same
   dimension. Encrypt one under the actual work public-key encryption routine,
   using independent secure randomness and a uniform hidden bit b.
3. Give the challenge ciphertext and its normal public producer metadata to
   the adversary. It returns a guess for b.

The missing premise is a bound epsilon on distinguishing advantage in this
experiment for the exact correlated key graph and sampler distributions.
An independent-secret RLWE estimate, a sparse-source attack estimate, or
separate estimates added together do not establish that premise. This is a
precise security experiment, not an accepted assumption or security grant.

## Public-evaluation lemma

Suppose the premise holds. For any adversary A that additionally obtains any
finite, adaptively selected history of permitted public arithmetic and refresh
operations, there is an adversary B in the experiment above with the same
distinguishing advantage. Its runtime is A's runtime plus the cost of the
public evaluations it simulates. There is no multiplicative loss in advantage
from the number of refresh cycles.

Proof: B forwards its setup material and challenge to A. Whenever A requests
an evaluation, B executes that public algorithm using the same public material
and inputs. If the interface draws independent public randomness, B draws it
from the same distribution. B returns A's final guess. This generates exactly
the real transcript, conditioned on either challenge bit, so the two advantages
are equal. This is a simulation proof, not an independence assertion about
keys in Setup.

The code satisfies the relevant evaluator-side condition: source conversion,
phase evaluation, G/H extraction, affine restoration, inverse slots, key return,
and acceptance receive no secret or client decoder. Error and capacity refusals
use producer-issued public bounds and ciphertext structure. Progress callbacks
contain public stage names/counts. The local canonical-root identity derives
from ciphertext lineage, not plaintext, and root acceptance uses local sealed
capabilities. A proof simulator can reproduce those handles internally without
knowing b; it does not require adding a raw-import escape hatch to the runtime.

Client decryption, an observed-secret-error callback, an external plaintext
oracle, or an arbitrary caller certificate would fall outside this lemma.
None is an evaluator input in the supported path. Physical side channels and
remote execution authentication are outside this IND-CPA model.

## Correctness versus confidentiality

The separate correctness argument uses the source support certificate,
`G(rho+pK)/p = K*G'(rho) mod p`, the inverse-derivative H, and the checked
return bound. It establishes `m_returned=m_input mod65537`, hence equality of
canonical representatives and preservation of the logical S8 projections.
It does not establish the joint-setup premise. Conversely, the confidentiality
lemma does not establish arithmetic correctness or useful return headroom.

The sparse-source estimator work addresses specific attacks on one domain.
Even a completed run of the newly located authors' attack implementation
cannot prove the joint premise. The exact publication inventory and source
fingerprint specify what a future joint/KDM reduction or reviewed assumption
would have to cover. Production admission remains closed until that obligation
and the required concrete attack-model assessment are satisfied.
