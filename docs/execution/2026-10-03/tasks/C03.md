## Implementation steps

- Specify little-endian byte layout, version, context/key identifiers, coefficient-domain/Montgomery tags, level, ordered lane counts and exact lengths.
- Validate header and checked size arithmetic before allocation; reject noncanonical residues, unknown version/domain/level, wrong context and trailing data.
- Encode main-only ciphertext/public/evaluation-key objects as applicable. Keep certified history trust policy distinct from parsing validity.
- Reconstitute and validate the internal root/frame contract after import using S05; the main-Q wire boundary is not permission to discard the priming substrate.

## Acceptance criteria

- Roundtrip preserves every main-Q lane exactly. Public schema/role metadata may describe the intact internal root; no unreviewed secret-dependent auxiliary residue is serialized. Derived public views must rebind to the admitted source after import.
- Truncated, oversized, duplicate/wrong lanes, trailing bytes, wrong key/context and altered domain fixtures all refuse without panic.
- An old anchor-bearing DualRNS serialization is rejected.
