## Implementation steps

- Implement private CertifiedCiphertext/CertifiedNoiseBound fields with context, key-domain and provenance binding.
- Only checked encryption and certified operations issue trusted bounds. Raw imports are Uncertified until an explicit trusted-client or authenticated-history policy supplies a valid bound.
- Remove any route that mutates a ciphertext under an unchanged certificate or wraps arbitrary bytes as fresh. Maintain independent state for DAG forks and joins.
- Require exact scalar/division support semantics; clone copies the state but cannot reset it.

## Acceptance criteria

- External code cannot construct or mutate certified fields; compile-fail tests exercise this boundary.
- Swapped bytes, key domain, level or context invalidate admission; resetting a display ledger has no effect.
- Two branches evolving independently have correct bounds on join.
