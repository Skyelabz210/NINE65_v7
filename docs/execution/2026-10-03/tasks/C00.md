## Implementation steps

- Add a small main-only evaluator wrapper around ExactMulEvaluator and existing main-RNS add/plain operations; bind a context and key family.
- Create separate client and public evaluation bundles; main-only public/gadget keys only. The evaluator API has no secret-key or s² argument.
- Keep the old CramPublicEvaluator explicitly legacy until callers migrate. Preserve an honest route/emission ledger; do not relabel materialization as lane-local.
- Do not expose exact_divide as arbitrary integer division: document modular-unit semantics and require an appropriate bound/encoding contract before any stronger claim.
- Honor S00 root and frame interfaces in the wrapper shape; C00 alone is the arithmetic backend milestone, not completed Safe Basis integration. S05 must establish the actual preserved substrate.
- Use the existing ExactMulEvaluator tensor path and ExactScaleRound remainder-adjusted FPD for inexact BFV rescale on all components. Derive coherent auxiliary inputs before tensor multiplication; preserve the current signed rounding rule and N/2 bound for d1.
