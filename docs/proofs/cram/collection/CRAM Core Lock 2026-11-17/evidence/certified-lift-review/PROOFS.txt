Theorem 2 (T5: inverse discipline; the Fermat trap). For gcd(a, m) = 1 the extended Euclidean
algorithm returns s with as ≡ 1 (mod m), correct for every modulus m. The Fermat expression
a m−2 mod m equals a−1 only when m is prime; on composite m it is in general wrong.
Proof. The algorithm produces integers s, t with as + mt = gcd(a, m) = 1; reducing mod m gives
as ≡ 1. No primality of m is used. For the Fermat expression, a m−2 ≡ a−1 iff a m−1 ≡ 1 (mod m).
By Fermat’s little theorem this holds for all units when m is prime, but for composite m the order
of a divides the Carmichael function λ(m), which is typically far smaller than m − 1, so a m−1 ̸≡ 1
in general.

Witness. m = 15015 = 3 · 5 · 7 · 11 · 13, a = 2: ext-Euclid gives 2−1 = 7508 (indeed 2 · 7508 = 15016 ≡ 1),

every inverse in libcram is ext-Euclid, never Fermat.

Theorem 8 (T7: lane independence — the von Neumann bypass). Let F = i fi act on i Z/pi Z
by (F (v))i = fi (vi ). Then applying the per-lane updates in any order yields the same result, and
lane i’s output depends only on lane i’s input.
Proof. By definition the i-th coordinate of F is fi (vi ), a function of vi alone. Updates to distinct
coordinates act on disjoint state, so any two of them commute; by induction every scheduling of
the k updates produces the same tuple. No coordinate ever reads another, so there is no cross-lane
data dependence.

Witness. m1 lane independence order invariant: scrambled update orders agree with the canonical
order. This is the dependency-level statement of “compute in memory”: the residue layout is already the
parallel program.

Theorem 9 (T8: the lane oscillator has an exact, non-decaying period). On a prime lane p
with gcd(a, p) = 1, the orbit xt+1 = a xt , x0 = 1, is purely periodic with period ordp (a), and

Proof. (Z/pZ)× is a finite group of order p − 1; xt = at lies in it. The order of a divides the group

Theorem 16 (T13: the covering-space orientation arrow). Let r = X mod MS and K = ⌊X/MS ⌋.
Then (K, r) orders Z≥0 in agreement with the natural order (T4); r is a coordinate on the torus
Z/MS Z and K is the winding, an unbounded lift to the covering line. The deck transformation
K 7→ K + 1 corresponds to X 7→ X + MS , which fixes r and advances the lap.

Proof. The order-isomorphism is T4. For the deck map, (X +MS ) mod MS = X mod MS = r while
⌊(X + MS )/MS ⌋ = K + 1; thus the phase is invariant and only the winding advances. Faithfulness
of the phase (distinct moments in a lap have distinct r) is T9, which is what makes K a legitimate
time coordinate rather than a lossy one.

Theorem 17 (T14: shadow entropy and reversibility). For a step g on a finite state set with
uniform input, Hshadow (g) = 0 iff g is injective. A clean carried step (advancing (r, K), or any
lanewise bijection) is injective, hence reversible with Hshadow = 0. A synthetic step that discards the
winding across L laps (equivalently, fuses lanes) is L-to-one, hence non-injective with Hshadow =
log2 L > 0 and not invertible. Consequently irreversibility holds iff a synthetic (non-injective)
operation is introduced.

Proof. On a finite set, g injective ⇐⇒ every fibre g −1 (y) is a singleton ⇐⇒ the conditional
entropy H(input | g(input)) = 0 under uniform input; this is the definition of Hshadow . A clean
carried successor is a bijection (T9, T13), so Hshadow = 0 and it is invertible. The discard map
X 7→ X mod MS on [0, L MS ) has every fibre of size exactly L (the L laps sharing a residue), giving
H(input | output) = log2 L. Non-singleton fibres are precisely the collapse produced by breaking
the homomorphism; absent such a step the map is injective and reversible.

Witness. shadow arrow.py: 21,315 checks — the clean successor has maximum fibre size 1; the quotient-
discard over L laps has every fibre size L and is non-invertible.
