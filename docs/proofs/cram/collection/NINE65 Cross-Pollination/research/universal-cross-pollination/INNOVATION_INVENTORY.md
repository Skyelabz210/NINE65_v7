# NINE65 innovation inventory and return paths

Source snapshot: `88a7bdadbf0e1f8fbfdb2b37e9843101b8db3484`; inspected 2026-11-12. This is a source-based research inventory, not a new whole-workspace execution certificate. The linked Codex task could not be read because this session exposes no `read_thread` tool; its title supplies no evidence for this inventory.

The strongest organizing opportunity is a **query-aware exact-computation layer**: a consumer specifies what it needs to know, a producer supplies authentic observations sufficient for that query, and the implementation transports the query without first materializing every underlying coordinate. This applies to arithmetic, trajectories, clocks, invariants and application aggregates. K-Elimination is a particularly cheap constructor in that larger layer. The constructions below identify concrete opportunities to connect existing work, including connections that feed back into CRAM itself.

## Derived connections that deserve proof and implementation

These are written deductions from the primitives above, not claims of newly compiled Lean results or newly benchmarked speedups.

### 1. MAA reflections, quotient dynamics and time folding share one transport problem

`MAAElement::reflect(i)` replaces a coordinate by

\[
k_i'=2\sum_{j\ne i}k_j-k_i,
\]

and leaves the other coordinates fixed. Write this integer-linear map as `S_i`. It is an involution: after one reflection the sum of the other three coordinates is unchanged, so the second update gives `2s-(2s-k_i)=k_i`. It preserves the Descartes quadratic form

\[
Q(k)=2\sum_j k_j^2-(\sum_j k_j)^2.
\]

For the changed coordinate `t=k_i` and fixed sum `s`, its contribution to `Q` is `t²-2st` plus a term independent of `t`. Replacing `t` by `2s-t` leaves that expression unchanged. Thus a valid Descartes quadruple remains valid over the integers, subject to the implementation's capacity checks. The identities also hold after reduction modulo any modulus.

Now let `B` observe a modular or linear quotient of the four-coordinate state. The reflection descends to a well-defined update on observations precisely when `ker(B)` is stable under `S_i`. Indeed `Bx=By` means `x-y` lies in the kernel, and therefore `B S_i x=B S_i y` exactly when that kernel is preserved. This is the dynamic companion to target-query recoverability.

**New return path:** the same certificate can govern CRAM operator transduction, Apollonian orbit queries, repeated linear PDE stencils and phase transformations. Products of admitted reflections can be folded by matrix powering on the observed quotient. The integer problem may have large curvatures while the desired invariant or orbit predicate has a much smaller exact observation. Prove the kernel-stability test and commuting square before promising state reduction; not every observation is stable under every update.

### 2. GRO timestamp recovery is the same nonunit resolution law

For accumulator modulus `N=2^n`, define the oriented phase difference

\[
z_t=(\Delta_A-\Delta_B)t\pmod N.
\]

With `delta=Delta_A-Delta_B` and `d=gcd(delta,N)`, the kernel in integer time is `(N/d)Z`. Hence the observation determines `t mod (N/d)`, and determines `t mod N` exactly when `delta` is odd. This agrees with `GroGate::coincidence_period`, which computes `N/d`; the generic constructor permits nonmaximal cases, while the golden-ratio constructor adjusts parity.

**New return path:** use the existing general/nonunit K-Elimination certificate to validate oscillator synchronization and relative event numbering. Avoid confusing the *oriented* difference with `phase_diff`, which folds to circular distance and loses a further sign choice. Likewise the Boolean `is_window` is a much coarser query. An event-index query must use the actual supplied observation and its real fibers. This gives a precise contract for phase-clock integration, including refusal when a consumer requests finer time resolution than the clock supplies.

### 3. Triad cross-engine checks become exact under a bounded-difference certificate

At equal scale, agreement of every S8 lane implies

\[
x-y\equiv0\pmod{9{,}699{,}690}.
\]

It proves `x=y` if a certified bound gives `|x-y|<9,699,690`. Without that bound, `x=0` and `y=9,699,690` are an immediate alias. Scalar equality implies equality of all residues, so the source banner's claim that lane equality is *strictly stronger* than scalar equality is mathematically reversed. Residues are nevertheless valuable independent witnesses and can be cheaper or easier to distribute.

**New return path:** replace informal engine agreement with an observation-and-error certificate. Two engines each provide a rigorous enclosure of the same real quantity and a specified rounding rule; a sufficiently narrow intersection or difference bound plus residue agreement certifies an identical rounded integer. Additional authentic anchors can extend the certified difference window. This combines K-Elimination, QMNF error accounting and provenance into a useful exact-output verification protocol without confusing a finite integer approximation with the real transcendental itself.

### 4. Softmax normalization and conservative transport are the same invariant shape

Let integer weights `a_i>=0` satisfy `S=sum a_i>0`, choose output total `T`, and take `q_i=floor(T a_i/S)`. Then

\[
0\le T-\sum_iq_i<n.
\]

The left inequality follows from summing floors; the strict upper bound follows from summing fractional remainders. Assigning this residual budget preserves the total exactly. The repository puts the deficit into a maximal output; distributing it to the largest exact remainders is an alternative policy that keeps each output within one unit of its ideal rational allocation. Choosing between them changes the allocation semantics and must be explicit.

**New return path:** represent total mass as a conserved target query across normalized neural outputs, private-feedback allocations and conservative lattice/PDE stencils. Shared sum certificates can catch implementation errors without observing every coordinate. Accuracy of approximated exponential weights remains a separate bound; conservation does not prove softmax accuracy. A hidden selection of largest remainders would also require an encrypted comparison implementation.

### 5. Lane scheduling can follow the consumer's algebraic demand

Given observation `B` and consumer queries `C_1,...,C_s` satisfying `ker B ⊆ ker C_j`, the joint query satisfies the same criterion because its kernel is the intersection of the individual kernels. A postprocessing query `F(C_1(x),...,C_s(x))` needs no additional source information. This provides a compiler rule: fuse compatible consumers of the same authentic source epoch, materialize only their ephemeral query results, and retain the original immutable observation binding.

**New return path:** combine the public consumer/anchor planner with UNHAL's deterministic lane runner. Keep public schedule selection separate from secret data; do not let data-dependent query demand silently become a side channel. The scheduler should account for observation production, inverse preparation, width, lane count, encrypted work and transfer cost. A ring-level O(1) readout and a many-lane FHE run use different cost models.

### 6. Approximation, ambiguity, authenticity and implementation cost need separate certificates

Several families become stronger when four concerns are explicit:

1. **Ambiguity:** which source differences remain invisible to the observation?
2. **Accuracy:** what real/integer rounding or discretization error is admitted?
3. **Authenticity:** why are the observations from the stated source, key domain and epoch?
4. **Cost:** which operations, bit widths and producer costs were counted?

K-Elimination closes the first question for its admitted query. QMNF enclosures can address the second; phase-root and typed evidence producers address the third; deterministic execution and measured kernels address the fourth. Their conjunction is a reusable cross-framework capability contract. No one certificate silently substitutes for the others. This is a constructive route to broader universality: the abstract theorem stays small, while domain-specific constructors discharge explicit obligations.

## Priority for integration

First, give on-demand evidence a common source/frame/epoch/query identity and consume it in a proof-directed public planner. Second, use the current lift-aware transduction seam and deterministic executor to implement one bounded end-to-end workload with an explicit output query. Private-feedback aggregation and Triad cross-engine verification are small enough to supply decisive evidence before touching the full encrypted refresh path. Third, prove dynamic kernel stability once and reuse it for MAA reflections, linear stencil folding and operator transduction. Fourth, introduce rigorous interval/error objects so the QMNF and tropical branches can specify what their finite observations establish about continuous targets.

These steps develop the generality by adding independently justified constructors and consumers. They preserve the distinctive architectural contribution while making each newly enabled domain concrete, falsifiable and reusable by NINE65.
