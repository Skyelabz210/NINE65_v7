## Additional literature check

Hung and Parhami, *Fast RNS division algorithms for fixed divisors with application to RSA encryption*, Information Processing Letters 51 (1994), 163–169, [author-hosted PDF](https://web.ece.ucsb.edu/~parhami/pubs_folder/parh94-ipl-rns-div-fixed-divisors.pdf), was fetched through the literature connector. Relevant introduction and §§2.2–2.5 were read. The extractor omits/mangles some later formulas, so this is an excerpt-level review, not a full reconstruction of both algorithms.

The paper explicitly says its first reciprocal algorithm does not require the divisor to be coprime to all moduli, while its second algorithm does. Its sign path can fall back to mixed-radix conversion, and its stated O(n) times use n parallel residue processors. These concrete facts correct blanket statements in the supplied survey. They do not demonstrate an earlier equivalent of CRAM's complete source-bound on-demand architecture.

A targeted search for a prior RNS gcd algorithm mostly returned unrelated polynomial-gcd or setup-inversion references. No stronger priority conclusion was drawn from those results. Exact quotient/remainder suffices constructively for Euclid; the included residue-only reference model demonstrates that closure directly.
