1.  What a Functor Actually Requires
A functor F: 𝒞 → 𝒟 between two categories requires three things simultaneously:

•  (a) Object map:  for each object X ∈ Ob(𝒞), a target object F(X) ∈ Ob(𝒟).
•  (b) Morphism map:  for each morphism f: X → Y in 𝒞, a morphism F(f): F(X) → F(Y) in 𝒟.
•  (c) Composition preservation:  F(g ∘ f) = F(g) ∘ F(f)  for all composable f, g in 𝒞.
•  (d) Identity preservation:  F(id_X) = id_{F(X)}  for all X in 𝒞.

The PSPI white paper (Theorem 3.1) establishes condition (a) via 7 correspondences. Conditions (b), (c), and (d) require morphisms to exist in both categories — and no morphisms are defined anywhere in the document.

DIAGNOSIS:  Φ(f∘g) = Φ(f)∘Φ(g) is not unprovable because it is false.  It is unprovable because f and g are not defined — the expression is ill-typed.  This is not a weakness in the mathematics; it is an incompleteness in the specification.

3.  Three Candidate Fixes
Each fix assigns explicit morphisms to both categories. The fixes are ordered by mathematical strength.

Fix A — Thin Category (Preorder Interpretation)  [RECOMMENDED]
Strength: Strongest provable claim.  The composition law becomes automatic. All content is in verifying monotonicity.

Define both categories as preorders (thin categories, at most one morphism between any two objects):

  A ≤_𝒮 B    iff    B structurally depends on A in NINE65 (data-flow DAG)
  P ≤_𝒫 Q    iff    Q analytically depends on P in prime spectral theory

In any thin category, the composition law Φ(f∘g) = Φ(f)∘Φ(g) is AUTOMATIC because:
•  At most one morphism exists between any pair of objects.
•  If A ≤ B and B ≤ C in 𝒮, there is exactly one morphism A → C (the transitive witness).
•  Φ sends it to the unique morphism Φ(A) → Φ(C) in 𝒫.  There is no choice — the equation holds trivially.

The real content of Fix A is the monotonicity condition:

  MONOTONICITY LEMMA (Fix A):  For all A, B ∈ Ob(𝒮):    A ≤_𝒮 B  ⟹  Φ(A) ≤_𝒫 Φ(B)

Identity preservation is also automatic in thin categories: id_X is the unique reflexivity morphism X ≤ X, and Φ sends it to the unique id_{Φ(X)}.

Fix B — Concrete Arithmetic Category  [PARTIALLY PROVABLE]
Strength: Strongest mathematical claim, hardest to prove.  Assigns explicit arithmetic maps as morphisms.

Morphisms in 𝒮 are exact arithmetic/computational maps:
•  CRT decomposition map:  ℤ → ∏_i ℤ/p_i ℤ  (decomposes integer into residue tuple)
•  K-Elimination map:  (r, s) ↦ (s − r)·M⁻¹ mod A  (recovers winding number)
•  NTT transform:  ℤ_q[X]/(X^n+1) → ℤ_q^n  (butterfly evaluation)
•  Shadow entropy extraction:  quotient q ↦ H_min(q)  (entropy measurement)

Morphisms in 𝒫 are analytic/number-theoretic maps:
•  Ramanujan-sieve map:  SP(p, ·): ℤ → ℚ  (T6-1 formula)
•  Gap derivation:  n ↦ p_{n+1} − p_n  (prime gap function)
•  Hardy-Littlewood singular series:  d ↦ C_2(d)  (density correction)
•  Zeta zero spectrum:  n ↦ γ_n  (imaginary parts of ρ_n on critical line)

OBSTRUCTION:  Correspondence 2.1 (Montgomery quotient ↔ prime gap) is a structural analogy, not a map-level proven correspondence. Until an explicit arithmetic map f: quotient-space → gap-space is constructed and shown to commute with composition, Fix B cannot be completed for all 7 correspondences.

Fix C — Profunctor / Correspondence  [PROVABLE NOW]
Strength: Weakest claim, but fully honest about current state.  No composition law required.

A profunctor (distributor) Φ: 𝒮 ↛ 𝒫 assigns to each pair (S ∈ Ob(𝒮), P ∈ Ob(𝒫)) a set of bridging relations, with no requirement that these relations compose.

Under Fix C, the 7 correspondences ARE the profunctor. Each correspondence defines a bridging relation between one NINE65 object and one prime spectral object. No additional proof is needed.

Fix C is the mathematically correct current classification for Conjecture 3.1.  It honestly represents what is proven (7 object-level correspondences)  without overclaiming functor structure that requires undefined morphisms.

6.  The Single Remaining Obstacle
To upgrade from Conjecture 3.1 to Theorem 3.1 (full concrete functor) requires exactly one thing: an explicit arithmetic map for Correspondence 2.1.

6.1  What is Needed
Correspondence 2.1 pairs Montgomery quotient q_{k,i} with prime gap g_n = p_{n+1} − p_n. The structural analogy is:
•  Both are 'near-bijections of input': q_{k,i} is essentially determined by the input integer x (modulo M), and g_n is essentially determined by the prime index n.
•  Both measure 'how far you are from the next modular landmark': q_{k,i} counts winding wraps around M; g_n counts steps to the next prime.

What is needed is an explicit map  f_{2.1}: ℤ/Mℤ × ℤ/Aℤ → ℤ≥1  sending a (residue, anchor-residue) pair to a prime gap, such that:
  K-Elimination ∘ f_{2.1}  =  f_{2.1} ∘ (gap function)
This commutation would make Φ a genuine functor on morphisms for correspondence 2.1.

6.2  Candidate Construction
The most natural candidate is the map:
  f_{2.1}(r, s)  :=  K-Eliminate(r, s)  =  (s − r) · M⁻¹ mod A
This sends a residue pair to a winding number k ∈ {0, 1, ..., A−1}, which represents the 'gap count' in the modular crystal. The claim would then be:
CANDIDATE CLAIM:  Under the substitution M = primorial(B), A = anchor prime, and x ranging over prime-adjacent integers, the distribution of K-Eliminate(x mod M, x mod A) matches the distribution of prime gaps g_n via the T6-1 formula.  Specifically: P[K-Elim = k] = SP(A, k) for k in the safe basis.

This is empirically testable against the existing K-Elimination test suite (10⁸ cases). If confirmed, it would provide the map-level correspondence needed for Fix B.

RECOMMENDED NEXT ACTION:  Run the existing K-Elimination test suite with M = 30030 (primorial of S6) and A ∈ {97, 101, 103} (primes outside S6), recording the distribution of winding numbers k.  Compare against SP(A, k) predictions from T6-1.  Matching distributions would establish f_{2.1}.
